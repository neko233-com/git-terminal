Git-Terminal

Local product verification

The Go 1.27.3 + MyGo client is the only terminal implementation here. task verify is the mandatory local gate; task test-race is an explicit separate gate that fails without a C compiler.

The gate runs gofmt, go vet, shuffled uncached go test ./..., go run ./cmd/checklocales, the no-Rust guard, a trimmed build with the Ghostty VT library, and headless CLI smoke checks. All checks run locally; no GitHub Actions and no desktop-interaction result is claimed.

The no-Rust guard refuses *.rs, Cargo files and Rust toolchain calls in this repository, and checks that external git-next evidence allowlists no longer name this repository's Rust paths.

See the verification note for the gate order and the Go implementation note for scope, prerequisites and the Ghostty notice.
