Git-Terminal

Local product verification

The git-next bundle invokes Rust formatting, clippy, workspace unit tests and the real PTY shell gate through its Go terminal-product-acceptance command. Profiles are disposable and the owned Git/Bash distribution is explicit. Real Windows desktop acceptance is a separate gate.

The rounded-clip fixture is included inside the vendored Windows renderer, copied from locked gpui-fast 0.1.10. Image-render trait methods follow the dependency test-support feature. Production rendering is unchanged.

SSH configuration accepts both Host=alias and Host = alias; equals signs in values remain data.
