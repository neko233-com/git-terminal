Git-Terminal

Go-only client: the independent application is implemented in Go 1.27.3 with MyGo's GPUI-style native UI and terminal plugin. go/ is the single source of truth; there is no Rust tree, Cargo build or GPUI Fast vendor in this repository.

A native terminal for Windows with tabs, an owned Bash default plus PowerShell and CMD profiles, ConPTY sessions, shell integration and git-next identity validation. POSIX builds use a real ptmx PTY through the MyGo plugin. There is no Git GUI interface.

Tabs, Unicode and Chinese input, ANSI/true color, selection, scrollback, bracketed paste, copy/paste, zoom and resize are part of the terminal. The mygo terminal view drives ConPTY/ptmx sessions directly; no external terminal window is opened.

git-terminal --cwd D:\Code\project
git-terminal --shell powershell
git-terminal --print-setup --json
git-terminal language list
git-terminal language set zh-Hans
git-terminal language set en
git-terminal language set auto
git-terminal language get

Ctrl+T opens a tab, Ctrl+W closes it, and Ctrl+Tab / Ctrl+Shift+Tab switches tabs. Ctrl+Shift+T/W remains available. Ctrl+Shift+C/V copies/pastes, Shift+PageUp/PageDown scrolls and Ctrl +/- zooms. Drag, double click or triple click selects. Shift bypasses application mouse reporting.

Settings live in %APPDATA%\git-terminal\settings.json (or the XDG config directory on POSIX). The interface language follows the device preferred-UI language until one is selected; every language is a JSON document in go/locales/, so adding one needs no code change. Names earlier releases accepted keep working.

Shells and git-next

The bundled default is its owned Bash shell when that runtime is installed. PowerShell and CMD profiles are available. A session prepends the verified git-next bin directory (and its owned runtime paths when present) to the inherited PATH, and only then sets MSYSTEM. A runtime without Bash selects the native PowerShell or CMD profile.

--git selects an absolute git-next executable; its identity is checked with version --json. A non-git-next executable is refused. Shell processes, streams, exit, resize and cleanup stay under explicit SessionManager ownership; closing a session twice is harmless and leaks no process.

--no-profile skips user startup files and --no-shell-integration selects ordinary shell startup. Explicit --command execution keeps normal command and exit semantics.

Local checks

task verify runs formatting, vet, shuffled uncached tests, the Go locale checker, the no-Rust guard, a trimmed build with its Ghostty VT library and headless CLI smoke checks. task test-race is an explicit separate gate. No GitHub Actions are used. Terminal contents, credentials and environment secrets are never written to public evidence.

The native Ghostty VT library is shipped beside the executable; its upstream source, checksum and license note are in the Ghostty notice. Windows ConPTY requires Windows 10 1809 or later; POSIX builds use ptmx. Windows x64/ARM64 binaries belong to the matching git-next MSI.
