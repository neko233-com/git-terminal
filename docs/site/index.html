Git-Terminal

A native Rust + GPUI Fast terminal installed with the Windows git-next MSI. Real ConPTY sessions render inside the application. Bash, PowerShell and CMD share the installed git-next runtime.

Windows combines tabs and native window controls in one title bar. Its original terminal/branch icon is embedded in the EXE at nine sizes and appears in Explorer, taskbar, Alt+Tab and installed shortcuts. Native drag regions, resize and Snap behavior remain available. No WebView is used.

Desktop tests preserve clipboard formats eagerly in memory; they do not log clipboard contents or retain remote OLE proxies. Unsupported formats fail before any change.

Tabs, Unicode and Chinese input, ANSI/true color, selection, scrollback, bracketed paste, copy/paste, zoom and resize are part of the terminal. There is no Git GUI interface.

git-terminal --cwd D:\Code\project
git-terminal --shell powershell
git-terminal --print-setup --json
git-terminal language set chinese
git-terminal language set english
git-terminal language get

Ctrl+T opens a tab, Ctrl+W closes it, and Ctrl+Tab / Ctrl+Shift+Tab switches tabs. Ctrl+Shift+T/W remains available. Ctrl+Shift+C/V copies/pastes, Shift+PageUp/PageDown scrolls and Ctrl +/- zooms. Drag, double click or triple click selects. Shift bypasses application mouse reporting.

The dark native window gives priority to tabs and the command area, with a 16px monospace default and coordinated syntax/ANSI colors. Tabs show directory and branch; new tabs inherit the active directory. The + button opens a tab; its adjacent dropdown selects the default shell or interface language. The footer shows directory and active shell. Many tabs scroll horizontally, and closing another tab preserves the selected session.

Settings: %APPDATA%\git-terminal\settings.json. Language follows the system until selected. The bundled default is owned Bash. Shell profiles and credential storage retain their normal locations.

Shell highlighting and Git prompt

The managed Bash input uses native Rust coloring for commands, options, strings, variables, comments and unfinished quotes. It retains Bash readline editing, history and completion. No third-party line editor is loaded. Coloring changes only displayed input cells; command output and alternate-screen applications retain their own colors. PowerShell loads native PSReadLine; CMD keeps its native editor. The Bash prompt shows directory and branch, including parent repositories, worktree .git files and detached HEAD. Prompt updates read HEAD without scanning all files.

User profile files are read without modification. The managed Bash rc file reads the normal login profile chain inside an interactive non-login shell. Use --no-shell-integration for original login shell behavior. Disable syntax_highlighting to turn off native coloring; disable git_prompt to use your own prompt. Native Bash coloring follows the managed prompt. --no-profile skips user startup files; explicit commands retain ordinary execution and exit status.

Sessions preserve the launcher's explicit environment overrides, including HOME and temporary directories. Windows installation initializes the pinned runtime mount configuration; acceptance stages those defaults in a disposable copy without modifying frozen packages.

Git-Terminal is a peer Git submodule of git-next. Local formatting, lint, PTY, desktop and MSI checks provide release evidence. Compilation is distinct from runtime acceptance. Attribution and changes.

SSH hosts and SFTP

Open SSH in the title bar. Add or import explicit OpenSSH aliases, group hosts, and connect in native tabs. User, port, identity and config file are optional; blank port respects SSH config. System OpenSSH is preferred on Windows for native agent support. Keys, certificates, ProxyJump and known_hosts retain OpenSSH behavior. Passwords/passphrases use terminal login or the native background authentication dialog and are never saved in hosts.json.

Select a host for SFTP. Click folders, go up with ↑, choose Upload…, or drop Explorer files/directories into the file pane. Right-click an entry for Download…. Two transfers run concurrently; the bounded queue supports cancellation and shows progress. Large directories use a virtual list. Transfers use 64 KiB blocks with 16 requests in flight.

Individual files use staging names and atomic completion. Replacing a remote file requires confirmation and POSIX rename support. Directory transfers merge per file. Symbolic links/reparse points and unsafe local names are rejected. The original destination survives cancellation/failure; remote .part cleanup is best effort after a network loss. Requests time out after 60 seconds without activity. Closing the last tab keeps active transfers visible; exiting cancels owned processes.

Linux monitoring

The remote panel shows OS/timezone, uptime, CPU cores and a trend, memory/cache, network counters/rates, per-device disk I/O and capacity. It reads /proc and /sys over one SSH connection, requires no agent and does not need root. First-sample rates wait for a second sample. Set a per-host interval (1/2/5/10 seconds) or pause/resume. Closing the panel/changing hosts stops sampling. SSH/SFTP work independently of the Linux-only monitor.

git-terminal remote import C:\Users\you\.ssh\config
git-terminal remote add production user@example.invalid --group Production
git-terminal --ssh production
git-terminal remote list production /srv
git-terminal remote put production .\build /srv/build
git-terminal remote get production /srv/logs .\logs
git-terminal remote monitor production --count 2

Hosts live in %APPDATA%\git-terminal\hosts.json. Existing configuration that cannot be loaded is not overwritten silently. Failed SSH tabs keep their output and offer Reconnect. Ctrl+T duplicates the active SSH host; the shell menu opens a local profile.

Responsiveness

Local prompt discovery stops at filesystem/drive/share roots and avoids double-slash UNC probes. Normal branch/worktree/detached HEAD display reads metadata without launching Git. The app uses system ConPTY; writes and resize calls stay off the UI thread. Hidden tabs answer VT queries without repainting, while output bursts yield to keyboard/window events.

Desktop runtime validation targets Windows x64; Windows ARM64 is cross-built separately. Mac desktop runtime acceptance is not claimed. Download the git-next bundle.
